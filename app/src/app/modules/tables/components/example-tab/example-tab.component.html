picture_as_pdf

Generador de Reportes PDF con Plantillas HTML

El backend utiliza Jinja2 para inyectar datos en plantillas HTML con header.html y footer.html reutilizables, convirtiéndolos a PDF mediante pdfkit / wkhtmltopdf.

directions_car Reporte de Flota

Exporta la tabla completa de vehículos con sus seriales y estado GPS.

groups Reporte de Clientes

Exporta el directorio de propietarios con teléfonos, correos y planes de pago.

inventory_2 Reporte de Inventario

Exporta el inventario valorizado con existencias, precios y stock mínimo.

code ¿Cómo crear un nuevo reporte en Core?

  1. Crea tu plantilla HTML en core/api/templates/tu_reporte.html utilizando sintaxis Jinja2 ({{ '{{ data_view[\'campo\'] }}' }}).
  2. Usa la función render_template_to_pdf() en core/api/utils/pdf.py pasando el nombre de la plantilla y tu diccionario de datos.
  3. Retorna el archivo con FileResponse(path, filename, media_type="application/pdf") y limpieza en background.
  4. En Angular, usa apiService.getBlob() para recibir el archivo binario y descargarlo en el navegador.
