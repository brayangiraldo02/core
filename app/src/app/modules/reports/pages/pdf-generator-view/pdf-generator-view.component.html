Generador de Reportes PDF

Módulo para la generación y exportación de documentos oficiales con plantillas HTML y Jinja2

picture_as_pdf

Motor de Renderizado PDF (Jinja2 + pdfkit / wkhtmltopdf)

El backend utiliza Jinja2 para inyectar datasets dinámicos en plantillas HTML que incluyen header.html (con logo, fecha/hora y nombre del sistema) y footer.html (con paginación y usuario emisor), convirtiéndolos a PDF de alta resolución mediante pdfkit / wkhtmltopdf.

directions_car Reporte de Flota

Exporta el catálogo de vehículos con placas, clientes asociados, tipo de vehículo, seriales y estado de conexión GPS.

groups Reporte de Clientes

Exporta el directorio de propietarios con teléfonos, correos electrónicos, valores de administración y planes de pago.

inventory_2 Reporte de Inventario

Exporta el inventario valorizado con existencias actuales, costos unitarios, precios de venta y estado de stock.

code ¿Cómo crear un nuevo reporte en Core?

  1. Crea tu plantilla HTML en core/api/templates/tu_reporte.html utilizando sintaxis Jinja2 ({{ '{{ data_view[\'campo\'] }}' }}).
  2. Usa la función render_template_to_pdf() en core/api/utils/pdf.py pasando el nombre de la plantilla y tu diccionario de datos.
  3. Retorna el archivo con FileResponse(path, filename, media_type="application/pdf") y limpieza en background.
  4. En Angular, usa apiService.getBlob() para recibir el archivo binario y descargarlo en el navegador.
